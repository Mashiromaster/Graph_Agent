## 根因

BSP 语义下 root 不可能综合子节点产出:root 在 superstep 1 跑完进入终态,
子节点在 superstep 2 才运行,而节点只执行一次、永不重入。所以 root 的终文本
必然只是"已提交子任务、待返回后综合"的承诺。

实测一例(mid/A2/brief-storage/s0):root 输出 802 字符承诺,三个子节点共产出
25210 字符真实内容;八个子问题的必需关键词在全图文本里**全部命中**,而只看
root 得 0/8。

可用新口径离线重算——这正是留存 transcript 的价值。
